# Election Night Checklist - VxCentralScan

### [Central Scanning](scanning-ballots.md)

* [ ] [VxCentralScan Hardware Setup](vxcentralscan-hardware-setup.md)
* [ ] Confirm VxCentralScan is in official ballot mode and has a "Total Sheets" count of 0
  * [ ] If not, toggle the scanner to official ballot mode from the `Settings` screen or select `Delete All Batches` from the `Batch History` screen
* [ ] Scan ballots in batches
* [ ] Create a pile of ballots for adjudication as rejected by the scanner
* [ ] Adjudicate ballots
* [ ] Scan adjudicated ballots
* [ ] Write down the number of ballots scanned by the scanner (displayed on `Scan Ballots` page)
* [ ] Go to the `Batch History` page and `Save CVRs` to the USB drive
* [ ] Power down VxCentralScan using the keyboard power button. VxCentralScan has shut down correctly when the screen is off and presents no content.
* [ ] Store system in a secure climate-controlled environment
