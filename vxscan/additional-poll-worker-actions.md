# Additional Poll Worker Actions

{% hint style="info" %}
The following steps must be completed by a poll worker.
{% endhint %}

## Pause or Resume Voting

The `Pause Voting` action in the poll worker screen is generally used by jurisdictions conducting early voting over multiple days or during an emergency situation. To pause voting and prevent ballots from being cast at VxScan:

* [ ] Insert a poll worker card and select `Menu`
* [ ] Select `Pause Voting`

<div><figure><img src="../.gitbook/assets/vxscan-pw-menu-button.png" alt="VxScan poll worker close polls prompt with the Menu button highlighted" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-pw-pause-voting-button.png" alt="VxScan poll worker menu with polls open and the Pause Voting button highlighted" width="375"><figcaption></figcaption></figure></div>

* [ ] Select `Reprint Voting Paused Report` to print more reports as necessary
* [ ] Remove the poll worker card

<div><figure><img src="../.gitbook/assets/vxscan-pw-voting-paused.png" alt="VxScan Voting Paused screen confirming the report printed, with Reprint Voting Paused Report" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-voting-paused.png" alt="VxScan Voting Paused screen prompting to insert a poll worker card to resume voting" width="375"><figcaption></figcaption></figure></div>

Voting is now paused. To resume voting:

* [ ] Insert a poll worker card and select `Resume Voting`

<div><figure><img src="../.gitbook/assets/vxscan-pw-resume-voting-button.png" alt="VxScan poll worker prompt Do you want to resume voting with the Resume Voting button highlighted" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-pw-voting-resumed.png" alt="VxScan Voting Resumed screen confirming the report printed, with Reprint Voting Resumed Report" width="375"><figcaption></figcaption></figure></div>

* [ ] Select `Reprint Voting Resumed Report` to print more reports as necessary
* [ ] Remove the poll worker card

The polls are now open.

## Printing Previous Reports

If additional copies of a report need to be printed at any time, insert a poll worker card and select `Menu` to access the poll worker menu. Select `Print [Type] Report` to print additional copies.

<div><figure><img src="../.gitbook/assets/vxscan-pw-print-polls-opened-report-button.png" alt="VxScan poll worker menu with polls open and the Print Polls Opened Report button highlighted" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-pw-print-polls-closed-report-button.png" alt="VxScan poll worker menu with polls closed and the Print Polls Closed Report button highlighted" width="375"><figcaption></figcaption></figure></div>

Additional reports can only be printed as long as no ballots have been scanned since the original report was printed.

## Printing Write-In Image Reports

If your jurisdiction enables write-in image reports on VxScan, you will see the option to `Print Write-In Image Report` after polls are closed. Select `Print Write-In Image Report` and print additional copies as needed.
