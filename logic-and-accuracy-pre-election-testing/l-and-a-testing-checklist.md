# L&A Testing Checklist

## VxAdmin - Part 1

* [ ] Set up VxAdmin
* [ ] Log in with the election manager card
* [ ] Select `Tally` from the side menu
* [ ] Verify there are no cast vote records (CVRs)
* [ ] Select `Reports` from the side menu
* [ ] Select `Full Election Tally Report` to print the zero report

## VxScan

* [ ] Set up VxScan
* [ ] Log in with the election manager card
* [ ] If your jurisdiction requires testing with official ballots, toggle mode to `Official Ballot Mode`
* [ ] Select the `More` tab
* [ ] Select `Set Date and Time` and verify the date and time
* [ ] Select the `Printer` tab
* [ ] Follow the instructions to load a new roll of thermal paper
* [ ] Print a test report
* [ ] Select the `Scanner` tab
* [ ] Select `Calibrate Double Sheet Detection`
* [ ] Follow the instructions to calibrate the scanner
* [ ] Remove the election manager card
* [ ] Insert the poll worker card
* [ ] Select `Open Polls`

The polls opened report prints. This is your zero report.

* [ ] Tear to remove the report
* [ ] Verify precinct name, election date, and totals are zero
* [ ] Remove the poll worker card
* [ ] Run test ballots through the scanner as required
* [ ] Insert the poll worker card
* [ ] Select `Close Polls`

The polls closed report prints.

* [ ] Tear to remove the report
* [ ] Verify results match expected test ballot results
* [ ] Remove the poll worker card
* [ ] Log in with the election manager card
* [ ] If you were testing in official ballot mode, select `Test Ballot Mode`
* [ ] Select `Official Ballot Mode`
* [ ] Verify "Sheets Scanned" count is 0
* [ ] Remove the USB drive
* [ ] Insert a new USB drive
* [ ] Select the `More` tab
* [ ] Select `Power Down`
* [ ] Unplug the power cord from VxScan and the outlet
* [ ] Insert the power cord into its storage location
* [ ] Clean the scanning unit
* [ ] Close, seal, and document the VxScan case as required

## VxAdmin - Part 2

* [ ] Log in with the election manager card
* [ ] Select `Tally` from the side menu
* [ ] Load CVRs from the USB drive(s)
* [ ] Verify counts match expected test ballot results
* [ ] Select `Remove All`
* [ ] Select `Remove All CVRs` to confirm
* [ ] Confirm there are no CVRs on VxAdmin
* [ ] Pack up VxAdmin
* [ ] Close, seal, and document the VxAdmin case as required
