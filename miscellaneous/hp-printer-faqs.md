# HP Printer FAQs

This FAQ applies to VxAdmin, VxPrint, and VxMark.

## Do We Need to Install Toner?

New printers come with toner pre-installed, see the [Supply List](supply-list.md "mention") for replacement options. To install a new toner cartridge, follow [HP's instructions](https://support.hp.com/us-en/document/ish_5455373-5578919-16). For the HP Color LaserJet Pro 4201dn, which has four toner cartridges (black, cyan, magenta, and yellow), follow the instructions in HP's user guide for the printer.

## The Printer Displays "Select Language" and Won't Print. What Do I Do?

Your printer is not fully configured. Configure the printer by responding to the on-screen prompts. You can press the OK button repeatedly, selecting all the defaults, until it says "Ready".

## How Do I Fix Streaks, Lines, or Otherwise Poor Print Quality?

Print a cleaning page. On the printer LCD screen, select `Setup` > `Printer Maintenance` > `Print Quality Tools` > `Cleaning Page`.

Printing the cleaning page usually clears the printer's rollers of stray ink that is causing print issues.

## What If Printing a Cleaning Page Helps, but the Issue Keeps Coming Back?

It's possible the paper you are using is not compatible with the printer. When toner doesn't print properly to a page, it can end up on the rollers where it causes streaks on later pages. Try printing another cleaning page or try a different type of compatible paper.

You may also try adjusting the default paper type. On the printer LCD screen, select `Setup` > `Tray Management` > `Default Paper Type` > `Mid-Weight 96-110g`.

Although printing is slower with this setting, it often fixes print quality issues.

If after all of the above you continue to have issues, the toner cartridge may be defective and may need to be replaced.
