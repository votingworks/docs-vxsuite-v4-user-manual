# Save the Election Package

To configure VxScan, VxCentralScan, VxMark, VxMarkScan, or VxPrint, you must first save the election package from VxAdmin to a USB drive.

* [ ] Select `Election` from the side menu
* [ ] Select `Save Election Package`

<figure><img src="../.gitbook/assets/vxadmin-sa-save-election-package-button.png" alt="VxAdmin Election screen with the Save Election Package button highlighted." width="375"><figcaption></figcaption></figure>

* [ ] If a USB drive isn't already inserted, insert a USB drive
* [ ] Select `Save`

<figure><img src="../.gitbook/assets/vxadmin-sa-confirm-save-election-package-modal.png" alt="VxAdmin Save Election Package dialog." width="375"><figcaption></figcaption></figure>

VxAdmin saves the election package to the USB drive.

* [ ] Select `Eject USB`

<figure><img src="../.gitbook/assets/vxadmin-sa-election-package-saved.png" alt="VxAdmin Election Package Saved dialog with Close and Eject USB buttons" width="375"><figcaption></figcaption></figure>

VxAdmin confirms once it is safe to remove the USB drive.

{% hint style="info" %}
The election package saved at VxAdmin is different from the election package used to configure your VxAdmin. VxScan, VxCentralScan, VxMark, VxMarkScan, and VxPrint can only be configured with election packages saved at VxAdmin.
{% endhint %}
