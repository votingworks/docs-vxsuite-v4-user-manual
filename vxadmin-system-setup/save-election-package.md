# Save Election Package

To configure VxScan, VxCentralScan, VxMark, VxMarkScan, or VxPrint, you must first save the election package from VxAdmin to a USB drive. You may do so as either the system administrator or the election manager. Select `Election` from the side menu and select `Save Election Package`.

<figure><img src="../.gitbook/assets/image (1).png" alt="" width="375"><figcaption></figcaption></figure>

If you don't already have a USB drive inserted, insert a USB drive. Then select _`Save`_ to save the election package.

<figure><img src="../.gitbook/assets/image (2).png" alt="" width="375"><figcaption></figcaption></figure>

VxAdmin will save an election package to the USB drive. Once the file is saved, select _`Eject USB`_. VxAdmin will confirm once it is safe to remove the USB drive.

{% hint style="warning" %}
The election package saved at VxAdmin is different from the election package used to configure your VxAdmin. VxMarkScan, VxScan, and VxCentralScan can only be configured with election packages saved at VxAdmin.
{% endhint %}
