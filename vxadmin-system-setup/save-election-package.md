# Save the Configuration Package

To configure VxScan, VxCentralScan, VxMark, VxMarkScan, or VxPrint, you must first save the configuration package from VxAdmin to a USB drive.

* [ ] Select `Election` from the side menu
* [ ] Select `Save Configuration Package`

<figure><img src="../.gitbook/assets/vxadmin-sa-save-configuration-package-button-highlighted.png" alt="VxAdmin Election screen with the Save Configuration Package button highlighted." width="375"><figcaption></figcaption></figure>

* [ ] If a USB drive isn't already inserted, insert a USB drive
* [ ] Select `Save`

<figure><img src="../.gitbook/assets/vxadmin-sa-confirm-save-configuration-package-modal.png" alt="VxAdmin Save Configuration Package dialog." width="375"><figcaption></figcaption></figure>

VxAdmin saves the configuration package to the USB drive.

* [ ] Select `Eject USB`

<figure><img src="../.gitbook/assets/vxadmin-sa-configuration-package-saved.png" alt="VxAdmin Configuration Package Saved dialog with Close and Eject USB buttons" width="375"><figcaption></figcaption></figure>

VxAdmin confirms once it is safe to remove the USB drive.

{% hint style="info" %}
The configuration package saved at VxAdmin is different from the election package used to configure your VxAdmin. VxScan, VxCentralScan, VxMark, VxMarkScan, and VxPrint can only be configured with configuration packages saved at VxAdmin.
{% endhint %}
