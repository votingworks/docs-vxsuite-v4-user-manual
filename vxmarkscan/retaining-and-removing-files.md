# Retaining and Removing Files - VxMarkScan

{% hint style="info" %}
These steps must be completed by a system administrator or an election manager.
{% endhint %}

VxMarkScan does not retain any type of ballot or voter data, so the only files to retain after an election are the logs.

## Retain Log Files

Logs are saved in the `/logs` folder on the USB drive. To save logs, insert a USB drive, then insert an election manager or system administrator card, and select `Save Logs`.

## Remove Election Files

To remove the election definition from VxMarkScan, select `Unconfigure Machine` from the election manager or system administrator menu and confirm by selecting `Delete All Election Data`.
