# Opening Polls

After VxScan is plugged in, the screen will show that polls are closed:

<figure><img src="../.gitbook/assets/vxscan-polls-closed-initial.png" alt="VxScan Polls Closed screen prompting to insert a poll worker card to open polls" width="375"><figcaption></figcaption></figure>

{% hint style="warning" %}
If there is an orange callout that says "Test Ballot Mode" on the screen, contact your election administrator immediately to prepare the machine for the election.
{% endhint %}

To open the polls:

* [ ] Insert the poll worker card into the card reader
* [ ] Select `Open Polls`. The polls opened report will start printing.

<div><figure><img src="../.gitbook/assets/photo-vxscan-insert-poll-worker-card.png" alt="Hand inserting a Poll Worker smart card into the VxScan card reader slot" width="188"><figcaption><p>Insert poll worker card</p></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-open-polls-button.png" alt="VxScan poll worker prompt Do you want to open the polls with the Open Polls button highlighted" width="375"><figcaption><p>Select <code>Open Polls</code></p></figcaption></figure></div>

* [ ] Gently tear the report against the tear bar.&#x20;
* [ ] If you see the `Print Next Report` button, select it. Gently tear the report against the tear bar. Repeat until there is no `Print Next Report` button.
* [ ] Select `Reprint Polls Opened Report` to print additional copies as necessary

<div><figure><img src="../.gitbook/assets/photo-vxscan-polls-opened-report-printing.png" alt="VxScan screen showing Opening Polls with the polls opened report emerging from the printer slot" width="188"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-polls-opened.png" alt="VxScan Polls Opened screen confirming the report printed, with Reprint Polls Opened Report" width="375"><figcaption><p>Select <code>Reprint Polls Opened Report</code> to print more reports</p></figcaption></figure></div>

* [ ] Remove the poll worker card

The polls are now open. The number of ballots scanned should be zero. Verify the polling place name and election date are correct in the bottom left corner.

<figure><img src="../.gitbook/assets/vxscan-insert-ballot-election-info.png" alt="VxScan Insert Your Ballot screen with the election name and precinct in the footer highlighted" width="563"><figcaption></figcaption></figure>

Below is an example of the polls opened report. All totals should be zero.

<figure><img src="../.gitbook/assets/vxscan-polls-opened-report.png" alt="Printed VxScan Polls Opened Report with signature lines and all contest totals at zero" width="375"><figcaption></figcaption></figure>

{% hint style="danger" %}
The poll worker door should remain sealed and secure at all times unless a poll worker requires access. Any unauthorized access should be reported to an election administrator immediately.
{% endhint %}
