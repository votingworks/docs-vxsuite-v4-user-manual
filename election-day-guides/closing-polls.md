# Closing Polls

* [ ] Insert the poll worker card
* [ ] Select `Close Polls`
* [ ] One copy of the polls closed report will print
* [ ] Tear to remove the report

<div><figure><img src="../.gitbook/assets/VxScan insert poll worker card 2.png" alt="" width="375"><figcaption><p>Insert poll worker card</p></figcaption></figure> <figure><img src="../.gitbook/assets/voting-021-close-polls-button.png" alt="" width="563"><figcaption><p>Select <code>Close Polls</code></p></figcaption></figure> <figure><img src="../.gitbook/assets/VxScan Polls Closed Report Printing.png" alt="" width="375"><figcaption></figcaption></figure></div>

* [ ] Select `Reprint Polls Closed Report` to print more reports as necessary
* [ ] Remove the poll worker card

<div><figure><img src="../.gitbook/assets/voting-024-reprint-polls-closed-report-button.png" alt="" width="375"><figcaption><p>Select <code>Reprint Polls Closed Report</code></p></figcaption></figure> <figure><img src="../.gitbook/assets/voting-025-polls-closed.png" alt="" width="375"><figcaption><p>Remove the poll worker card</p></figcaption></figure></div>

* [ ] Unseal and document the poll worker door seal as required
* [ ] Open the poll worker door
* [ ] Remove the USB drive from the poll worker door and secure as required

<div><figure><img src="../.gitbook/assets/VxScan poll worker door sealed.png" alt="" width="375"><figcaption><p>Unseal and document interior panel</p></figcaption></figure> <figure><img src="../.gitbook/assets/VxScan usb drive.png" alt="" width="188"><figcaption><p>Remove the USB drive</p></figcaption></figure></div>

The polls are now closed. Below is an example of the polls closed report.

<figure><img src="../.gitbook/assets/voting-038-polls-closed-report-multi-batch.png" alt="" width="375"><figcaption></figcaption></figure>

{% hint style="info" %}
Jurisdictions may configure VxScan to prevent closing the polls until the official polls close time on election day. If this is the case in your jurisdiction, logging in with a poll worker card before the polls close time will land you directly on the poll worker menu and `Close Polls` will be disabled. After the polls close time, you will be able to close polls as shown above.
{% endhint %}
