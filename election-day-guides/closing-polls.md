# Close Polls

Close the polls on VxScan at the end of voting to print the polls closed report.

* [ ] Insert the poll worker card into the card reader
* [ ] Select `Close Polls`

The polls closed report prints.

* [ ] Tear to remove the report
* [ ] If you see the `Print Next Copy` button, select it, gently tear off that copy, and repeat until the button no longer appears

<figure><img src="../.gitbook/assets/photo-vxscan-report-printing.jpg" alt="VxScan printing a report from the slot below the screen while the screen shows a progress indicator" width="375"><figcaption></figcaption></figure>

* [ ] Select `Print Another Copy` to print more reports as necessary
* [ ] Remove the poll worker card

<div><figure><img src="../.gitbook/assets/vxscan-polls-closed-report.png" alt="VxScan Polls Closed screen after the report prints, with the Print Another Copy button" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-polls-closed-final.png" alt="VxScan Polls Closed screen reading Voting is complete after the poll worker card is removed" width="375"><figcaption></figcaption></figure></div>

* [ ] Unseal and document the poll worker door seal as required
* [ ] Open the poll worker door
* [ ] Remove the USB drive from the poll worker door
* [ ] Secure the USB drive as required

<div><figure><img src="../.gitbook/assets/photo-vxscan-poll-worker-door-seal.jpg" alt="Numbered green plastic security seal threaded through the VxScan poll worker door latch" width="188"><figcaption><p>Unseal and document the poll worker door</p></figcaption></figure> <figure><img src="../.gitbook/assets/photo-vxscan-usb-drive-inserted.jpg" alt="USB drive inserted into the port behind the VxScan poll worker door, circled in blue" width="188"><figcaption><p>Remove the USB drive</p></figcaption></figure></div>

The polls are now closed. Below is an example of the polls closed report.

<figure><img src="../.gitbook/assets/vxscan-polls-closed-report-multi-batch.png" alt="VxScan Polls Closed Report with contest tallies and a Batch Summary table listing three batches" width="375"><figcaption></figcaption></figure>

{% hint style="info" %}
Jurisdictions may configure VxScan to prevent closing the polls until the official polls close time on election day. If this is the case in your jurisdiction, logging in with a poll worker card before the polls close time takes you directly to the poll worker menu and `Close Polls` is disabled. After the polls close time, you can close polls as shown above.
{% endhint %}
