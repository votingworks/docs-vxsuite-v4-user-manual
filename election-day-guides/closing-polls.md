# Closing Polls

* [ ] Insert the poll worker card
* [ ] Select `Close Polls`
* [ ] The polls closed report will print
* [ ] Tear to remove the report

<div><figure><img src="../.gitbook/assets/photo-vxscan-insert-poll-worker-card.png" alt="Hand inserting a Poll Worker smart card into the VxScan card reader slot" width="375"><figcaption><p>Insert poll worker card</p></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-close-polls-button.png" alt="VxScan poll worker prompt Do you want to close the polls with the Close Polls button highlighted" width="563"><figcaption><p>Select <code>Close Polls</code></p></figcaption></figure> <figure><img src="../.gitbook/assets/photo-vxscan-report-printing.png" alt="VxScan printing a report from the slot below the screen while the screen shows a progress indicator" width="375"><figcaption></figcaption></figure></div>

* [ ] Select `Reprint Polls Closed Report` to print more reports as necessary
* [ ] Remove the poll worker card

<div><figure><img src="../.gitbook/assets/vxscan-reprint-polls-closed-report-button.png" alt="VxScan Polls Closed screen with the Reprint Polls Closed Report button highlighted" width="375"><figcaption><p>Select <code>Reprint Polls Closed Report</code></p></figcaption></figure> <figure><img src="../.gitbook/assets/vxscan-polls-closed-final.png" alt="VxScan Polls Closed screen reading Voting is complete after the poll worker card is removed" width="375"><figcaption><p>Remove the poll worker card</p></figcaption></figure></div>

* [ ] Unseal and document the poll worker door seal as required
* [ ] Open the poll worker door
* [ ] Remove the USB drive from the poll worker door and secure as required

<div><figure><img src="../.gitbook/assets/photo-vxscan-poll-worker-door-seal.png" alt="Numbered green plastic security seal threaded through the VxScan poll worker door latch" width="375"><figcaption><p>Unseal and document interior panel</p></figcaption></figure> <figure><img src="../.gitbook/assets/photo-vxscan-usb-drive-inserted.png" alt="USB drive inserted into the port behind the VxScan poll worker door, circled in blue" width="188"><figcaption><p>Remove the USB drive</p></figcaption></figure></div>

The polls are now closed. Below is an example of the polls closed report.

<figure><img src="../.gitbook/assets/vxscan-polls-closed-report-multi-batch.png" alt="VxScan Polls Closed Report with contest tallies and a Batch Summary table listing three batches" width="375"><figcaption></figcaption></figure>

{% hint style="info" %}
Jurisdictions may configure VxScan to prevent closing the polls until the official polls close time on election day. If this is the case in your jurisdiction, logging in with a poll worker card before the polls close time will land you directly on the poll worker menu and `Close Polls` will be disabled. After the polls close time, you will be able to close polls as shown above.
{% endhint %}
