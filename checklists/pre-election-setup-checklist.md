# Pre-Election Setup Checklist

To prepare for an election, complete these steps after you download or receive the election package from VotingWorks and before logic and accuracy (L&A) testing.

## Retain Previous Election Files

### VxAdmin

* [ ] Log in with an election manager card
* [ ] Select `Reports` from the side menu
* [ ] Select `Full Election Tally Report`
* [ ] Select `Export Report PDF`
* [ ] Select `Export Report CSV`
* [ ] Select `Settings` from the side menu
* [ ] Select `Save Logs`

### VxScan

* [ ] Set up VxScan, without the ballot box
* [ ] Log in with an election manager card
* [ ] Select `CVRs and Logs` from the side menu
* [ ] Insert a USB drive
* [ ] Select `Save CVRs`
* [ ] Select `Save Logs`

## Remove Previous Election Files

### VxAdmin

* [ ] Log in with a system administrator card
* [ ] Select `Election` from the side menu
* [ ] Select `Unconfigure Machine`

### VxScan

* [ ] Log in with an election manager card
* [ ] Select `Unconfigure Machine`

## Configure VxAdmin

If you're creating the election on VxAdmin, complete [Create an Election](../vxadmin-system-setup/create-an-election/README.md) instead of loading an election package, then continue from "Verify the title and date of election are correct".

* [ ] Set up VxAdmin
* [ ] Log in with a system administrator card
* [ ] Insert USB drive containing the election package
* [ ] Select the file name of the correct election package
* [ ] Verify the title and date of election are correct
* [ ] Select `Settings` from the side menu
* [ ] Verify the current time and date are correct
* [ ] If you're not continuing to the next section, lock VxAdmin

## Create Election Manager & Poll Worker Cards

* [ ] Log in with a system administrator card
* [ ] Select `Smart Cards` from the side menu
* [ ] Insert card to program into the card reader
* [ ] Select the correct button for the card you are programming
* [ ] If you're programming an election manager card, record the PIN and keep it secure
* [ ] If you're not continuing to the next section, lock VxAdmin
* [ ] Securely store all cards

## Format USB Drives

* [ ] Log in with a system administrator card
* [ ] Select `Settings` from the side menu
* [ ] Select `Format USB Drive`
* [ ] Confirm you want to format the USB drive by selecting `Format USB Drive`
* [ ] Repeat for all USB drives you need to format
* [ ] If you're not continuing to the next section, lock VxAdmin

## Save Election Package

* [ ] Log in with a system administrator card
* [ ] Select `Election` from the side menu in VxAdmin
* [ ] Select `Save Election Package`
* [ ] When prompted, insert a USB drive
* [ ] Select `Save`
* [ ] Select `Eject USB`
* [ ] After VxAdmin confirms the USB drive is ejected, remove the USB drive

## Configure VxScan

* [ ] Log in with an election manager card
* [ ] Insert USB drive with the election package from VxAdmin
* [ ] If applicable, select the polling place VxScan is assigned to
* [ ] Verify the title and date of election are correct
