# Poll Worker Checklist

{% hint style="info" %}
These steps must be completed by a poll worker.
{% endhint %}

Complete these tasks during early voting and/or on election day.

## Set Up VxScan

1. **Set up the ballot box:**
   * [ ] Release the straps on each side
   * [ ] Secure the straps on the underside of the lid
   * [ ] Pull the box open
   * [ ] Gently push the purple hooks down with your foot
   * [ ] Close the lid, pushing until you hear a click
   * [ ] Seal the ballot box as required
2. **Set up the scanner:**
   * [ ] Place the case on top of the ballot box by lining up the bottom with the opening on the ballot box and sliding the case back
   * [ ] Remove and document the scanner case seal(s)
   * [ ] Push the button to release and open each latch
   * [ ] Open the lid of the case
   * [ ] Open the poll worker door (upper left corner)
   * [ ] Push the purple security bolt down to secure the case to the ballot box
   * [ ] Close the poll worker door
   * [ ] Seal and document the poll worker door as required
   * [ ] Remove the power cord from its storage place
   * [ ] Plug the power cord into the case
   * [ ] Plug the power cord into the Goldenmate uninterruptible power supply (UPS)
   * [ ] Plug the Goldenmate UPS into an outlet
   * [ ] Turn the Goldenmate UPS on

## Open Polls

For details, see [Open Polls](../election-day-guides/opening-polls.md "mention").

* [ ] Insert the poll worker card
* [ ] Select `Open Polls`

The polls opened report prints.

* [ ] Tear to remove the report
* [ ] If needed, select `Reprint Polls Opened Report` to print more
* [ ] Verify polling place name, election date, and totals are zero
* [ ] Sign, retain and/or display the polls opened report as instructed by your election administrator
* [ ] Remove the poll worker card

## Assist Voters

### Help a Voter Cast Their Ballot at VxScan

* [ ] Instruct the voter to insert their ballot in any orientation
* [ ] If the ballot scans successfully, let the voter know their vote has been cast
* [ ] If the ballot does not scan successfully, help the voter understand the issues with their ballot specified on the screen
* [ ] If the ballot does not scan successfully, explain the voter's options, which could include casting their ballot as marked, adding marks to their ballot, or receiving a new ballot

## Close Polls

* [ ] Insert the poll worker card
* [ ] Select `Close Polls`

The polls closed report prints.

* [ ] Tear to remove the report
* [ ] If needed, select `Reprint Polls Closed Report` to print more
* [ ] Retain and/or display the polls closed report as instructed by your election administrator
* [ ] Remove the poll worker card
* [ ] Unseal and document the poll worker door seal as required
* [ ] Open the poll worker door
* [ ] Remove the USB drive and secure as required

{% hint style="warning" %}
Single polling place jurisdictions may want to skip to the [Election Night Checklist](election-night-checklist.md "mention") at this time to verify cast vote records (CVRs) were properly saved before packing up equipment.
{% endhint %}

## Pack Up VxScan

1. **Pack up the scanner:**
   * [ ] Insert the poll worker card
   * [ ] Select `Power Down` to turn VxScan off
   * [ ] Once the screen has turned off, remove the power cord from VxScan
   * [ ] Remove the power cord from the Goldenmate UPS
   * [ ] Power off the UPS
   * [ ] Pack up the UPS
   * [ ] Wrap the power cord in its storage location
   * [ ] Push the purple release button to the left to release the case from the ballot box
   * [ ] Close the poll worker door
   * [ ] Close and latch the case lid
   * [ ] Seal and document the case seal(s) as required
   * [ ] Pull the case forward and lift the case off of the ballot box
2. **Pack up the ballot box:**
   * [ ] Unseal and/or unlock the ballot box
   * [ ] Remove all ballots from the ballot box
   * [ ] Seal the ballots into a secure container, recording the seal number as required
   * [ ] Press the latch on the lid to release the lid
   * [ ] Lift the lid over to the side
   * [ ] Fully collapse the ballot box by gently using your foot to lift the bottom purple hooks
   * [ ] Remove the straps from the underside of the lid
   * [ ] Tighten the straps around the side
