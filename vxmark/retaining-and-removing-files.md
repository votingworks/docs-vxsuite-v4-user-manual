# Retaining and Removing Files - VxMark

VxMark does not retain any type of ballot or voter data, so the only files to retain after an election are the logs.

## Retain Election Files

Logs are saved in the `/logs` folder on the USB drive. To save logs:

* [ ] Insert a USB drive
* [ ] Insert an election manager or system administrator card
* [ ] Select `Save Logs`
* [ ] Select a log format (VotingWorks recommends the `Default` format unless instructed otherwise)
* [ ] Select `Save`

## Remove Election Files

To remove the election configuration and all election data from VxMark:

* [ ] Select `Unconfigure Machine` from the election manager or system administrator menu
* [ ] Confirm by selecting `Delete All Election Data`
