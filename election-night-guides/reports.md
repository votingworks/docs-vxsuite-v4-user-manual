# Reports

Use the VxAdmin `Reports` screen to review, print, and export election results and ballot counts.

## Full Election Tally Report

To review results:

* [ ] Select `Reports` from the side menu
* [ ] Select `Full Election Tally Report`

A preview appears.

Select `Print Report` to print the report, `Export Report PDF` to save the election tally report to a USB drive as a .pdf file, or `Export Report CSV` to save the election tally report to a USB drive as a .csv file. Files are saved to a `reports/` folder on the USB drive.

<div><figure><img src="../.gitbook/assets/vxadmin-reports-full-election-tally-highlighted.png" alt="VxAdmin Election Reports screen with the Full Election Tally Report button highlighted" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxadmin-full-election-tally-report-actions-highlighted.png" alt="VxAdmin Full Election Tally Report preview with the Print and Export action buttons highlighted" width="375"><figcaption></figcaption></figure></div>

{% hint style="info" %}
The tally report includes any total write-in count of one or more in a contest. If a specific write-in candidate has enough votes to be considered in the outcome of a contest, the report lists that candidate and their vote total. The tally report doesn't list every write-in adjudicated—the write-in adjudication report has the full list.
{% endhint %}

## Tally Report Builder

The tally report builder allows you to create custom reports. These reports can be filtered or reported by precinct, district, ballot style, and more. To navigate to the tally report builder, select `Tally Report Builder` from the "Election Reports" screen.

<figure><img src="../.gitbook/assets/vxadmin-reports-tally-report-builder-highlighted.png" alt="VxAdmin Election Reports screen with the Tally Report Builder button highlighted." width="375"><figcaption></figcaption></figure>

To create a filtered and/or grouped report:

* [ ] Select `Add Filter`
* [ ] Select a filter type, e.g., ballot style, voting method, or precinct

<div><figure><img src="../.gitbook/assets/vxadmin-tally-report-builder-add-filter-highlighted.png" alt="VxAdmin Tally Report Builder with no filters added and the Add Filter button highlighted." width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxadmin-tally-report-builder-filter-dropdown-open.png" alt="VxAdmin Tally Report Builder with a new filter's type dropdown open listing ballot style, batch, precinct and more." width="375"><figcaption></figcaption></figure></div>

* [ ] Specify any specific ballot style(s), voting method(s), or precinct(s)
* [ ] If needed, select `Add Filter` to add an additional filter
* [ ] Select how you'd like the report grouped under "Report By"
* [ ] Select `Generate Report`
* [ ] If desired, print or export the report as a .pdf or .csv file

<div><figure><img src="../.gitbook/assets/vxadmin-tally-report-builder-generate-highlighted.png" alt="VxAdmin Tally Report Builder with a precinct filter and ballot style grouping set and Generate Report highlighted." width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxadmin-tally-report-builder-actions-highlighted.png" alt="VxAdmin Tally Report Builder after generating a report with the Print, Export PDF and Export CSV buttons highlighted." width="375"><figcaption></figcaption></figure></div>

## Write-In Adjudication Report

The write-in adjudication report presents how all write-ins were adjudicated and the count of votes for write-in candidates.

To print the report, select `Write-In Adjudication Report`. An example of the write-in adjudication report is on the right.
