# Reporting & Logs

### Reporting

Election managers and poll workers can view the number of ballots printed on the `Report` page. The page lists the number of precinct, absentee, and total ballots printed for each ballot style. You may use the search bar to narrow down the list to certain precincts or precinct splits:

<div><figure><img src="../.gitbook/assets/vxprint-pw-report-full.png" alt="VxPrint poll worker Report screen listing print counts for every precinct, party, and language" width="375"><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/vxprint-pw-report-filtered.png" alt="VxPrint poll worker Report screen filtered by the precinct name search box" width="375"><figcaption></figcaption></figure></div>

The report can be printed with the `Print Report` button or exported to a USB drive with the `Export Report PDF` button.

<figure><img src="../.gitbook/assets/vxprint-pw-ballots-printed-report.png" alt="Printed Ballots Printed Report listing print totals by precinct, party, and language" width="375"><figcaption></figcaption></figure>

### Saving Logs <a href="#saving-logs" id="saving-logs"></a>

In order to save logs, navigate to the `Settings` page and select `Save Logs`. Insert a USB drive. VotingWorks recommends the `Default` format unless instructed otherwise. Select `Save` and the logs will be exported to the USB drive.
